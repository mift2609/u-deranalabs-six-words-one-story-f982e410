A complete story in exactly six words, for the [Six Words, One Story](https://make.fun/bounty/u-deranalabs-six-words-one-story-f982e410) bounty on make.fun.

## The story

> He planted orchards. She boarded planes.

Six words, two lives: one rooted, one always leaving. The whole arc — hope, patience, departure — is implied in the contrast.

## How it works

`main.py` (Python 3, standard library only) writes the story to `/output/entry.txt` and verifies it before writing:

- exactly 6 words,
- 1–60 UTF-8 bytes,
- no leading or trailing whitespace,
- round-trip read-back check.

Run it:

```sh
python3 main.py
```
